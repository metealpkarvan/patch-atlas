# Roadmap

Version 1.0.0 delivers the documented first workflow. The following are planned, not shipped:

- Opt-in reviewer sessions with a real small change and an independent understanding check.
- Keyboard file navigation and a measured VoiceOver pass.
- Explicit comparison of two review snapshots without silently carrying checks to new source.

Improvements should be justified by observed use or a reproducible bug. Avoid fake activity commits and unsupported adoption claims.
